1. QUÉ ES ESTE PROYECTO (OBJETIVO)
--------------------------------------------------------------------------------
Aplicación web (dashboar) de "Seguimiento de producción de prendas" para un centro
de producción (SMS = Muestra de Venta). Permite:
  - Importar un archivo Excel de seguimiento.
  - Editar el estado de cada prenda y sus observaciones.
  - Ver un dashboard en vivo con KPIs y gráficos.
  - Exportar reportes en Excel y PDF.
  - Trabajar por módulos (Costura / Acabados) marcando prendas con check y guardar.

Tecnología: Streamlit (Python). Persistencia: SQLite. Despliegue: red local LAN.

DATOS DE NEGOCIO:
  - El "Style" es el código de la prenda, pero NO es único: se repite una vez por
    cada "Color Cuerpo". La clave real de cada registro es HOJA + STYLE + COLOR.
  - El PO actual es "SMS-01432". El prefijo "SMS" indica el cliente/tipo:
      SMS = Muestra de Venta. (No es PRODUCCION en este caso).
  - Datos: 76 estilos, 175 variantes, 54 estilos multi-color, PO único.
  - MULTI-HOJA: Cada hoja del Excel es un PROYECTO independiente (ej. STATUS
    SMS-SUMMER 27, WINTER, PEFIT...). Pueden coexistir varios proyectos en la DB.

5. MODOS RESPONDE A LA PREGUNTA DE CONCURRENCIA
--------------------------------------------------------------------------------
- Costura y Acabados escriben en la MISMA tabla SQLite, pero en registros distintos.
- SQLite serializa escrituras (un solo escritor) => no hay corrupción de datos.
- Si DIFERENTES variantes: no interfieren.
- Si LA MISMA variante: la última acción gana (queda el último estado).
- Los módulos Costura/Acabados SOLO se ven en modo editor (no en ?solo=1).
- En la práctica solo hay un editor, así que no hay conflicto real.

14. MULTI-HOJA / MULTI-PROYECTO (IMPLEMENTADO)
--------------------------------------------------------------------------------
OBJETIVO LOGRADO: Cada hoja del Excel = un proyecto independiente (ej. STATUS
SMS-SUMMER 27, WINTER, PEFIT...). Se pueden importar varias hojas y el dashboard
tiene un selector para ver una u otra.

FUNCIONAMIENTO ACTUAL:
  - Pestaña Importar: elige por CHECKBOXES qué hojas importar. Botón 'Importar
    datos seleccionados' importa solo las marcadas, cada una como proyecto aparte.
  - Selector 'Proyecto': aparece en el Dashboard, Seguimiento, Exportar y en el
    modo solo lectura. Sincronizan st.session_state.hoja_actual.
  - Cada pestaña filtra por la hoja seleccionada (db.obtener_todos(hoja=...)).
  - Costura/Acabados operan sobre la hoja activa; al guardar pasan la hoja a
    db.actualizar_seguimiento(hoja, ...).
  - Re-importar una hoja borra SOLO esa hoja, preserva las demás.
  - Modo solo lectura (?solo=1): selectbox de proyecto + dashboard. Soporta
    ?solo=1&hoja=NOMBRE.

CASOS EDGE MANEJADOS:
  - DB vieja sin columna 'hoja' → migración automática (se dropea y recrea).
  - Hoja sin filas válidas → error al importar, no se inserta nada para esa hoja.
  - Sin datos → selector vacío, muestra info.

NOTA: El Excel 'MISHA SMS 1 SE.xlsx' actualmente tiene UNA sola hoja
('STATUS SMS-SUMMER 27'), por lo que en la práctica hoy hay un solo proyecto.
La infraestructura multi-proyecto ya está lista para cuando se usen archivos
con varias hojas.
